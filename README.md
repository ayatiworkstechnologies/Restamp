# RESTAMP

RESTAMP is a modern, high-performance real estate & property discovery mobile application built with React Native and Expo (SDK 57).

## Features
- **Property Discovery**: Search, filter, and discover residential & commercial properties, plots, and villas.
- **Chennai Localities**: Explore top high-demand localities with market demand trends and price insights.
- **Verified Listings**: Curated verified properties with direct agent / owner contacts.
- **Shortlist & Saved**: Heart and save favorite properties for quick access.
- **Enquiries & Support**: Connect with property consultants and track site visit requests.
- **Owner & Seller Hub**: Post properties for sale or rent with zero brokerage options.

## Getting Started
```bash
npm install
npx expo start
```
